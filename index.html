About Pokeweb

Pokeweb is a browser-based Generation 5 Pokémon ROM editor for Pokémon Black, White, Black 2, and White 2. It edits game data from a user-selected .nds file and exports a modified ROM.

Editing tools

  • Pokémon: base stats, types, abilities, learnsets, evolutions, TM compatibility, sprites, and animations.
  • Trainers: teams, levels, moves, held items, battle types, and AI settings.
  • Encounters: wild Pokémon, levels, seasonal encounter tables, and encounter rates.
  • Moves and items: move properties, TM assignments, item data, move animation scripts, and particle resources.
  • Maps and text: map headers, overworld NPCs, warps, 3D map inspection, collision editing, and story and message text banks.
  • Documentation: ROM comparisons, PDF and text changelogs, and data exports for Dynamic Calc and Dynamic Dex.

Game support

Core data editing supports Black, White, Black 2, and White 2 when the required game data is loaded. Hidden Grotto and battle-facility editors are for Black 2 and White 2. Code patches and animation expansions have separate game, region, and ROM requirements; support for one game does not imply support for the others.

Loading and saving

Open NARCs to Load to select the game data available to the editors. Loading fewer data groups reduces memory use. Project data is saved in browser storage; use Export ROM to download the edited ROM. Keep a backup of the original file and test exported ROMs in an emulator.
