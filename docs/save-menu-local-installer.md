# B2/W2 save-menu installer

Version 0.3.12 is bundled under **Code Injection → Graphical/UI Enhancements → Black 2 / White 2 Save Menu** in this Pokeweb build. Installation accepts compatible English Black 2 / White 2 ROMs with an installed, enabled Following Pokémon patch regardless of the page's hostname.

With a save present, the menu plays the game's Relic Song sequence by default. The player walking loop and occupied downward-facing follower sprites change poses every eighth note using the sequence tick counter, so they follow its tempo changes. The song restarts after its natural ending and the previous sound state is restored when leaving the menu. The no-save screen keeps its native behavior.

The Music editor can add standalone stereo STRM songs without replacing any existing game track. Each added song receives a native stream ID and an in-ROM library manifest. The save-menu installer lists looping standalone songs and lets the user choose one, set its tempo from 30–300 BPM, and select one, two, or four sprite pose changes per beat. For streamed songs, pose changes follow the native stream playback position. **Off** silences the save menu while the previous BGM stays paused; walking and follower sprites then change poses every eight frames. The installer writes the 48-byte v2 `ui/save-menu/settings.bin` file; older 16-byte v1 settings remain readable. Relic Song remains the default. The installer verifies the Relic Song sequence only when that song is selected. It verifies the selected stream's content and looping flag when a standalone song is selected.

The top screen uses the native party-menu grid behind the save card and New Game button, with a cyan outer border following the native 64-frame selector fade. A filled faint gray emblem sits behind the save-card elements and is restored beneath animated sprites during walking and recalls. Its compact mask is embedded in the DLL without an additional heap buffer. The two gray header marks are replaced by an optional ROM version label. New installations default to `v1.0`; the installer accepts up to 30 supported game-font characters, and an empty field leaves the header clear. Its save-menu card links directly to the Following Pokémon installer. The label uses the former marks' gray.

On the saved-game card, press **L** for party slots 1–3, **R** for 4–6, **Y** for 1/3/5, or **X** for 2/4/6. Occupied Pokémon Hop through the follower's nine vertical positions without sound. The player uses the ROM's open-hand field pose (male 212:1, female 221:1); L and Y mirror it. Empty slots keep their Poké Ball placeholders. The music-driven walking pose counter continues through the Hop, so the sprites return on the current beat.

Hold **Select** with L to spin slots 1–3, R to spin slots 4–6, Y to spin slots 1/3/5, or X to spin slots 2/4/6 until released. X without Select retains its alternating-slot Hop. The spin cycles native follower directions down, left, up, and right every three frames, using the current walking foot phase in every direction. The save menu reads the installed follower registry and `a/0/4/8` artwork directly; it does not install a second sprite archive. An appearance without usable follower art shows the empty-slot placeholder.

Continue recalls the visible party from right to left. Each logical transition frame now lasts two display frames, making the recall, zoom, and jump take twice as long while retaining their easing and sound order. Pokémon turn cyan/white and shrink away without a ball effect. The player raises the ball through native Fly poses 1 → 2 → 3, holds until recalls finish, then reverses 2 → 1 → 0. After the recalls finish, a player sprite in a raised-leg walking pose jumps across the two screens onto the zoomed location marker, with the follower-mount sound at takeoff. The patch requires an installed, enabled Following Pokémon runtime and shares its artwork. Interiors use the town/route marker when their location label identifies one unique point. No-save menus use the original game screen. The native C-Gear question is skipped using the Yes fade/load path; native wireless errors remain visible. No-question saves keep their native direct load.

English B2/W2 and compatible hacks are accepted after native-code, Continue-dispatch, artwork, map-data, selected-sound, and module-conflict validation. Recognized 0.2.3 and 0.3.0–0.3.11 installations update without a second DLL. Active Main Menu Skip is refused. Failed validation or staging leaves the previous project installation intact.

Native source and build/harness tooling are maintained separately. Pokeweb ships `SaveMenuB2.dll`, `SaveMenuW2.dll`, `save-menu-map.lz`, and a generated compatibility manifest. The map installs as `ui/save-menu/map.lz` and is decoded through bounded streaming buffers. Standalone songs live in the ROM's SDAT; their manifest lives at `ui/streamed-music/library.json`.

Automated checks cover both game profiles, hosted/LAN/loopback availability, and follower dependency validation. A separately named White 2 Following Pokémon 0.7.44 test ROM was cold-booted in headless melonDS with a six-Meloetta save and the 153 BPM standalone track. Captures show six downward follower sprites, selected groups cycling directional poses, release restoring ordinary walking, and no Hop or spin sound calls. The 0.3.12 capture also shows the `v1.3` label in the former gray marks' position. The exported ROM has no `ui/save-menu/spin-art.narc` or `spin-index.bin`. Audio waveforms and Black 2 running-game behavior still need emulator acceptance.
