# Stock Black 2 Following Pokémon — 0.6.24-alpha

Pokeweb supports stock US Black 2, game code `IREO`, revision 0. The pinned
clean-ROM SHA-256 is
`2e6b2415354aa41471bc7617068dce059a59931bf5c4348a264f8043f297683a`.
Other regions, revisions, modified hook sites, and Black2Upgrade are rejected.

The Black 2 package provides the same stock feature set as the current White 2
package: automatic route following, Gen 5 artwork and forms, shiny and gender
variants, width-aware spacing, final draw correction, idle animation, ball
effects, generic and contextual conversations, one-time gifts, safe external
dialogue retention, PC/menu retention, ambient NPC collision, and seamless-zone
continuity. It uses Black 2-specific core, event, and field PMC modules. Shared
artwork and follower-owned data remain byte-identical where the retail archives
are identical.

`black2-contract.json` pins 21 hook sites and 329 native adapters. It is
generated by `black2_port.py`, which applies the reviewed Black 2 link-layout
translation to both source addresses and the contract, then reads expected bytes
from the pinned ROM. The build fails if the ROM hash, registry layout, resource
count, hook bytes, relocation set, module imports, or packaged ARMv5T branches
do not match.

Automated verification covers the binary contract, all 65,536 retail object
codes, descriptor offsets above 64 KiB, packaged relocation and stack behavior,
portable selection/movement/reaction logic, Pokeweb install/reinstall,
disable/enable, removal/reinstall, and export/reopen ownership. No Black 2 game
emulator or hardware run is claimed yet. Use [the Black 2 checklist](BLACK2-CHECKLIST.md)
for acceptance.

Build from the Pokeweb repository:

```sh
npm run following:verify-rom -- /path/to/clean-black2.nds
npm run following:build-black2 -- /path/to/clean-black2.nds
npm run following:build-black2 -- /path/to/clean-black2.nds --publish
FOLLOWING_PROFILE=black2 python3 runtime/following-pokemon/verify_runtime.py
npm run following:build-rom -- /path/to/clean-black2.nds
npx vite-node scripts/verify-following-install.ts /path/to/Black2-Following-0.6.24-alpha.nds
python3 runtime/following-pokemon/generate_black2_docs.py
```

The manual build is copied to the workspace parent as
`Black2-Following-0.6.24-alpha.nds`, with a same-basename save. Cold boot it;
states created with White 2 or another Black 2 ROM are not compatible evidence.
