# Six-Pokémon PWT

In **Code Injection → Minor Features/Add-ons**, install **Six-Pokémon PWT** and export the ROM. The patch supports US Black 2 (`IREO`) and White 2 (`IRDO`), revision 0.

Repeatable built-in cups require six eligible Pokémon per side in Singles, Doubles, Triple, and Rotation. Rental draws six per side from the selected rental pool. Mix uses the existing swap rules with the larger teams. The first Driftveil event uses its three-Pokémon story teams. Download Tournaments use their downloaded rules and teams.

Pokeweb generates a PMC DLL at install time. Overlay 55 supplies the team count and sets the loaded regulation's minimum and maximum for the repeatable cups. The ROM regulation records retain their source values for editing. Overlay 56 selects the six-Pokémon entry messages. The lobby's shared format description omits the retail team counts.

Custom opponents need enough eligible sets to complete a team of six under the tournament's species and held-item rules. Include the fixed lead in that total where the trainer has one.
