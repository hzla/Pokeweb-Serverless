## Emulator checks

Tested in melonDS headless against separately named ROMs. A separate Floccesy Town save copy was booted with the same 0.1.9 patch. The current Route 20 save was copied for testing; its source and test copies both have SHA-256 `3367b5e26f8c934a693a378b9fdbcfd1ba132999d863f9bf53f92275676500c9`. The source ROM hash remained unchanged. Empty-save tests used a different ROM basename. Version 0.1.9 was checked for saved and empty boot, animation stability, navigation, button and touch Continue with the 4× zoom, New Game actions, handoff, edge clamping, and two map labels. The earlier player, party-size, and badge variants remain visually applicable because the idle screen is pixel-identical to 0.1.8. Earlier native-map and map-edge comparisons remain applicable because the lower framebuffer was unchanged.

## Reference comparison and limits

The upper screen follows the dark grid and window-card structure of the supplied Platinum-hack reference at native 256×192 resolution. The trainer, time, and New Game text use the native White 2 glyphs with white ink and their gray shadow. A one-pixel gray name/time divider has a dot and short dash on each end, matching the supplied close-up. The trainer name and clock/time group align to the card's right edge; the walking trainer uses an oval ground shadow. The badge row has a gray two-compartment case frame and a gold bottom accent based on the supplied native badge case capture. The Save File, Trainer, Time, and Badges labels and the Story and Dex bars are omitted. The play time uses the reference's clock-icon format. The enlarged card places the animated party icons directly on its black background above all eight native badge-case images or their dark silhouettes. Empty party positions show gray Poké Balls modeled after the supplied party-row reference. The right-page indicator is a tall outlined triangle. The second page contains only a centered New Game button. The lower screen reproduces the native White 2 town-map artwork, location window, font, and marker animation at original proportions, following the later full-map request. The bottom control bar is removed as requested. On Continue, the map magnifies smoothly to 4× around a mapped saved location before the native loading handoff.

The location point record layout was cross-checked against independent B2W2 world-map research and the ROM's own location records. Per-location centering is superseded by the request to keep the whole map visible. Native icon lookup uses the ROM's species, form, and gender resolver; the Route 20 save exercised added icons, including Tapu Bulu. Other added forms were not covered by an end-to-end emulator test. The custom second page now exposes only New Game, as requested; the former Mystery Gift, Unova Link, Nintendo Wi-Fi Connection Setup, and Mic Test menu entries are no longer available from it.

For the zoom implementation, edge behavior, and module and heap outlook, see [ZOOM-FEASIBILITY.md](ZOOM-FEASIBILITY.md).
