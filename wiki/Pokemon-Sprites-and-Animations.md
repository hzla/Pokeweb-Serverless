# Pokemon Sprites and Animations

This page covers the Pokemon Sprite editor and the Animated Sprites/PWAN editor. These tools edit visual assets, palettes, icons, rig data, native DS animation files, GIF imports, and White 2 PWAN GIF overrides.

## Required Data

| Tool | Required data |
| --- | --- |
| Sprite editor | `personal`, `pokemon_sprites`, `pokemon_icons` |
| Native animation editing | `pokemon_sprites` files for the selected species/form |
| Starter sprite copy | `starter_sprites` through the [Starters](Starters) page |
| PWAN animated sprites | White 2 project with PMC and PWAN runtime installed through [Code Injection and Patches](Code-Injection-and-Patches) |

## Sprite Editor Controls

| Control | Meaning |
| --- | --- |
| Pokemon | Selects species. |
| Form | Selects form when the species has multiple sprite entries. |
| Import Bundle | Imports a `.pkmonspritebundle` generated by Pokeweb. |
| Raw Files | Exposes the 20 sprite-related subfiles for the selected sprite entry. |
| Sprites | Front/back and male/female sprite images. |
| Palettes | Normal and shiny palettes. |
| Icons | Pokemon menu icon variants and palette assignment. |
| Rig | Front/back rig atlas and cell data. |
| Animation | Native DS cell animation and multi-cell animation preview/editing. |

## Raw Sprite Files

Each Pokemon sprite entry uses 20 subfiles.

| File label | Meaning |
| --- | --- |
| Front Sprite | Main front battle sprite. |
| Front Female Sprite | Female front variant, when used. |
| Front Rig | Front rig/atlas image. |
| Front Female Rig | Female front rig variant. |
| Front NCER Cells | Cell definitions for the front sprite. |
| Front NANR Animation | Native front cell animation. |
| Front NMCR Multi-Cells | Front multi-cell layout groups. |
| Front NMAR Multi-Cell Animation | Front multi-cell animation timeline. |
| Front NCEC Rig Cells | Front rig-cell metadata. |
| Back Sprite | Main back battle sprite. |
| Back Female Sprite | Female back variant. |
| Back Rig | Back rig/atlas image. |
| Back Female Rig | Female back rig variant. |
| Back NCER Cells | Cell definitions for the back sprite. |
| Back NANR Animation | Native back cell animation. |
| Back NMCR Multi-Cells | Back multi-cell layout groups. |
| Back NMAR Multi-Cell Animation | Back multi-cell animation timeline. |
| Back NCEC Rig Cells | Back rig-cell metadata. |
| Palette | Normal palette. |
| Shiny Palette | Shiny palette. |

## Native Animation Tabs

| Tab | Meaning |
| --- | --- |
| Preview | Plays the assembled native animation. |
| NANR | Cell animation frames. |
| NMAR | Multi-cell animation frames. |
| NMCR | Multi-cell definitions, or groups of cells that move together. |

## GIF Flipbook Import Controls

| Control | Meaning | Example |
| --- | --- | --- |
| Packing mode | How the importer packs GIF frames into DS sprite/rig resources. | Use the default unless debugging space issues. |
| Sampling strategy | How source GIF frames are sampled. | Manual or automatic sampling. |
| Speed scale | Multiplies playback speed. | `1` normal, `0.5` slower, `2` faster |
| Downscale percent | Reduces source art before packing. | `100`, `75`, `50` |
| Output scale percent | Scales final generated output. | `100` |
| Loop start/end frame | Frame range used for looping. | start `1`, end `24` |
| Loop count | Number of times to repeat the loop when generating. | `1` |
| Manual frames | Explicit frame list for manual sampling. | `1,3,5,7` |

## PWAN Animated Sprites

PWAN is Pokeweb's White 2 GIF override path. It compiles front and back GIFs into a custom archive and stages runtime code so the game can display them.

| Field/control | Meaning |
| --- | --- |
| Pokemon | Species/form target for the override. |
| Front GIF | Source front animation GIF. |
| Back GIF | Source back animation GIF. |
| Palette source | Which native palette side should be used as the base. |
| Save Override | Compiles GIFs into PWAN data and stores the override in project state. |
| FPS | Playback rate derived from or applied to the PWAN timeline. |
| Scale | Scales generated frames. Allowed range is `0.5-2`. |
| Scale mode | `nearest` is direct scaling; `outlineFill` can help preserve outlines. |
| Outline threshold | Threshold for outline-fill scaling. Range `0-128`. |
| Offset X / Offset Y | Moves rendered frames. Range `-48` to `48`. |
| Apply | Saves edited PWAN side settings. |
| Download GIF/PNG | Exports preview frames for checking. |

## Common Workflows

| Goal | Steps |
| --- | --- |
| Replace a front sprite | Select Pokemon/form, open Sprites, import or replace the front sprite, then verify palette. |
| Import a full sprite bundle | Use Import Bundle and verify front, back, icons, palettes, and animations. |
| Edit native animation movement | Open Animation, select a part/frame, adjust transform, and preview playback. |
| Add GIF animated sprites in White 2 | Install PMC and PWAN support, open Animated Sprites, provide front/back GIFs, save override, export ROM. |

## Caveats

Native DS sprite formats have tight palette, tile, and cell limits. GIF imports can fail or look wrong if the source has too many colors, large motion, or frame sizes that do not fit the target format. PWAN avoids many native limits but currently supports White 2 code layouts only.
